# Fork changes to upstream files

Lavender is a fork of [LRCGET](https://github.com/tranxuanthang/lrcget).
New functionality lives in new files. This table records every edit made to a
file that also exists upstream, so merges from upstream stay small and every
conflict can be resolved against a known reason.

Rules:

- Prefer a new file (Rust module, Vue component, workflow) over editing an
  upstream file. When an upstream file must change, keep the edit to a hook
  point of a few lines.
- Record each edit here with the file, the lines or symbols touched, and why.
- With "Lyrics source" set to Online, the app must behave exactly like upstream.
- Publishing and flagging always use the online LRCLIB instance.
